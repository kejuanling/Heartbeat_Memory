编辑 AI 记忆

批量导入手写摘要

每段以 边界: 首消息id..尾消息id（推荐，稳定不漂移）、[首id..尾id] 或 块 #N 开头，正文接其后可多行，段间空行分隔。
工作流：用「导出」生成文件 → 让 AI 保留每块第一行的边界标记并重写摘要 → 粘贴回来点「解析预览」→ 确认后「导入」。
导入后：旧摘要自动进历史版本（最多 8 条，可查看/恢复），块变为待替换（需手动点替换才生效）。

批量导入记忆 · JSON

JSON 格式（与导出对齐）：顶层数组或 {items:[...]}，每条 {category?, content}。
category 可选：fact / rule / quote / milestone（或旧类名 关于她/认账/拓本），缺省或留空=自动识别。
导入去向固定为「待审」：全部条目进记忆 Review 队列人工裁决，不会直接入库。
