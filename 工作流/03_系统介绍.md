## 接入方式

> **说明**：以下“主方案”与“备用方案”描述的是**人类管理员登录服务器或进行故障排查**时的推荐入口。对于 **Agent 自动化操作**（读写文件、执行命令、查看日志等），请参考 `02_本地Agent工作方法.md` 第2节，优先使用 yun MCP 工具（`mcp__yun__*`），当 MCP 不可用时回退至 SSH/SCP。

- **主方案：SSH + 本地镜像**（连接参数见 `02_本地Agent工作方法.md`）。
- **备用方案：MCP yun-mcp-v2**：streamable-http 地址 `http://120.76.99.224:9010/mcp`，传统 SSE 老协议客户端用 `http://120.76.99.224:9010/sse`（`/legacy-sse` 为其兼容别名）；鉴权 header `X-API-Key`（也接受 `Authorization: Bearer`、Cookie、URL 参数 `X-API-Key`，值在 `yun-mcp-v2/config.json` 的 `api_key`），支持 CORS 可浏览器直连。**ChatGPT 连接器专用公网入口**（2026-09-18 加）：`https://dqbnv.ccwu.cc/<40位随机段>/mcp`（streamable；随机段即访问钥匙，明文只存 nginx `conf.d/dqbnv.conf`，不写文档；真实 X-API-Key 由 nginx 经 `conf.d/mcp-upstream-key.conf`(600) 注入，客户端无须带鉴权）。
- **MCP mcp-tools（工具集）公网入口**（2026-09-19 加）：`https://dqbnv.ccwu.cc/tools/<另一40位随机段>/mcp` → `127.0.0.1:8771`；随机段即钥匙（明文只存 `conf.d/dqbnv.conf`），真实 Bearer Token 由 nginx 经 `conf.d/mcp-tools-upstream-key.conf`(600) 注入（后端本就强制 `Authorization: Bearer`，Token 在 `.env` 的 `MCP_TOOLS_API_TOKEN`）。tools_server.py 为手写 JSON-RPC（非 SDK），2026-09-19 已做标准兼容补丁（git bdeb990：initialize 版本回显/通知 202/GET 405；git 2441c4d：POST 响应 SSE 单消息包裹——OpenAI 客户端只认 text/event-stream），标准客户端 ChatGPT/Trae 可直连；同日 443 块加 `/.well-known/` → 404（防 SPA 兜底污染 OAuth 探测，含前后缀两种形态，ACME 在 80 块不受影响）。

## 会话级配置接口与数据文件（`/opt/dylan-heartbeat/data/`）
前端统一走 `/heartbeat/admin/*`（nginx 去前缀到网关 `/admin/*`），均 GET/PUT、basicAuth：
- `/admin/current-session` GET/PUT → `data/current-session.json`（当前打开会话，跨设备同步）
- `/admin/session-names` GET/PUT → `data/session-names.json`（会话改名映射）
- `/admin/session-pins` GET/PUT → `data/session-pins.json`（会话置顶）
- `/admin/wake-locked` GET/PUT → `data/wake-locked.json`（锁定唤醒会话集合；网关内唤醒调度器只对这些会话各自独立计时、各自唤醒）
