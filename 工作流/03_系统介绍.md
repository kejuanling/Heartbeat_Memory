## nginx 路由（`/etc/nginx/nginx.conf`）
- `/heartbeat/` → 网关 3000（去前缀）
- `/admin` → 301 `/heartbeat`
- `/v1` → 3000
- `/todo|/diary|/monthly` → 8777
- `/ocr-api` → 8790
- `/papers/api/` `/co-api/` `/screenshot-api/` `/xie-diary/api/` → 3000（门户类只读接口；`/xie-diary/` 页面为 workspace/xie-diary/ 静态直出）
- `/` → 门户（301 → `/chat`）；`/chat` → 聊天（静态 `chat.html`）；未命中路径兜底回 `/index.html`（SPA 式，故下线的 /decision-trail/ 也落门户首页）

## 会话级配置接口与数据文件（`/opt/dylan-heartbeat/data/`）
前端统一走 `/heartbeat/admin/*`（nginx 去前缀到网关 `/admin/*`），均 GET/PUT、basicAuth：
- `/admin/current-session` GET/PUT → `data/current-session.json`（当前打开会话，跨设备同步）
- `/admin/session-names` GET/PUT → `data/session-names.json`（会话改名映射）
- `/admin/session-pins` GET/PUT → `data/session-pins.json`（会话置顶）
- `/admin/wake-locked` GET/PUT → `data/wake-locked.json`（锁定唤醒会话集合；网关内唤醒调度器只对这些会话各自独立计时、各自唤醒）

## 凭据键名（`/opt/dylan-heartbeat/.env`，值不写明文）
- `ADMIN_USER` / `ADMIN_PASSWORD`：管理台 basicAuth
- `INTERNAL_API_KEY`：内部 `/internal/*`
- `TARGET_API_URL` / `TARGET_API_KEY` / `MODEL_NAME`：LLM
- `BARK_KEY`、`USER_DISPLAY_NAME`
- 敏感值一律不写进文档；改鉴权时从服务器 `.env` 读。
